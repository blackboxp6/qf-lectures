# References & Bibliography

Every citation used anywhere on this site is collected here, organized by module. Citations in lectures use author–year inline form (e.g. `(Markowitz, 1952)`) and link back to this page. Only real, verifiable sources are used — no fabricated authors, DOIs, or results. Where a primary source is paywalled, a working-paper or official-documentation equivalent is linked instead.

## How citations work on this site

- Inline citations appear as `(Author, Year)` in lecture text.
- Each lecture also has its own **References** section at the bottom listing only the sources used in that lecture.
- This page is the canonical, deduplicated bibliography across the whole site.
- Sources are drawn from: peer-reviewed journals, arXiv/SSRN preprints, textbooks, and official documentation or data providers (Federal Reserve/FRED, SEC, BIS, IMF, World Bank, CFA Institute, NBER, university lecture notes, and library documentation for NumPy/pandas/SciPy).
