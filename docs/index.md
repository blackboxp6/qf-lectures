# Quantitative Finance Lectures

**A rigorous, free, and open curriculum in quantitative finance** — built from first principles across mathematics, statistics, stochastic calculus, derivatives pricing, portfolio theory, and machine learning.

</div>

This project exists for two reasons: to give myself a disciplined, first-principles path through quantitative finance, and to leave behind a public resource that shows the work — not just the conclusions. Every lecture derives its mathematics, implements it in Python, and cites the primary literature it draws from.

## What this is

- **A structured curriculum**, from prerequisite mathematics through advanced stochastic models and machine learning for markets.
- **Derivation-first**: every formula is derived, not just stated, and every variable is explained in financial terms.
- **Code-backed**: every lecture includes reproducible Python implementations using NumPy, pandas, SciPy, and matplotlib.
- **Cited**: every empirical claim and named result traces back to a real, verifiable source — academic papers, textbooks, or official data providers. See [References & Bibliography](references/index.md).

## What this is not

This is an educational resource, not investment advice. Code examples are pedagogical demonstrations, not production trading systems, and are clearly labeled as such.

## Curriculum overview

| Module | Focus |
|---|---|
| 0. Prerequisites | Python, calculus, linear algebra, probability, statistics, optimization |
| 1. Financial Foundations | Returns, instruments, market structure, portfolios |
| 2. Statistics & Econometrics | Estimation, regression, time series, ARCH/GARCH, cointegration |
| 3. Portfolio & Risk | Markowitz, CAPM, VaR, Expected Shortfall, Monte Carlo |
| 4. Derivatives | Options, arbitrage, Black-Scholes, Greeks, implied volatility |
| 5. Stochastic Finance | Brownian motion, Itô calculus, SDEs, risk-neutral pricing |
| 6. Quantitative Trading | Backtesting, biases, momentum, mean reversion, stat-arb |
| 7. Advanced Quant Finance | Heston, SABR, HMMs, Kalman filters, RMT, microstructure |
| 8. Machine Learning for Finance | Feature engineering, leakage, boosting, explainability |
| 9. Research Laboratory | The full research workflow, end to end |

See the [Curriculum](curriculum.md) page for the detailed, lecture-by-lecture breakdown and current build status.
