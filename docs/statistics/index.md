# Module 2 — Statistics & Econometrics

The statistical machinery behind empirical finance: distributions, estimation, hypothesis testing, regression and regularization, PCA, stationarity, time-series models (AR/MA/ARIMA), volatility modeling (ARCH/GARCH), and cointegration.
